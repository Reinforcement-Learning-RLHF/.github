# 🤖 Reinforcement Learning - RLHF

Welcome to the **Reinforcement Learning - RLHF** organization!

This is a project under [**Wat.ai**](https://watai.ca/), the University of Waterloo's AI student design team. You can learn more about Wat.ai and their other projects on [the website](https://watai.ca/projects).

This organization serves as the central workspace for our reinforcement learning project, where we explore how robots can learn complex tasks using **Reinforcement Learning from Human Feedback (RLHF)**, preference learning, and modern AI techniques.

Our goal is to build an open, collaborative environment where ideas evolve into experiments, experiments become prototypes, and prototypes become working systems.

---

## 🚀 What You'll Find Here

As the project develops, this organization will host:

* 🤖 Robot learning environments
* 🧠 Reward model training
* 📊 Preference datasets
* 🎥 Trajectory generation and evaluation
* 🔬 Experiments and research prototypes
* 📚 Documentation and technical notes

Whether you're interested in robotics, reinforcement learning, or AI research, you'll be able to follow our progress here.
